# Demo script

Total spoken time: about 170 seconds. Do not add a title card that claims a measurement or a void that is not on screen.

Record only what the owner performs. Do not composite a PayPal window. If the void is not completed in this recording, say so and stop. The stored capture evidence cannot be narrated as a void.

## Shot list

| Time | Shot | Say |
| --- | --- | --- |
| 0:00–0:20 | Title on the live page, no photo yet | A desk can look right in a photo and still not fit the corner, the clearance, or the budget. SpaceProof checks those constraints before the payment is captured. |
| 0:20–0:45 | Sample room, then the dashed suggestion | This is a drawing, not a measured room. Nebius proposes a placement area. It does not return millimeters. |
| 0:45–1:10 | Drag the rectangle, then the feet and inches fields | I can move it. The feet and inches are what I confirm. Changing them makes the earlier check out of date. |
| 1:10–1:35 | Nook Desk FitPass, then Studio Desk blocked | Nook Desk fits this confirmed opening. Studio Desk does not, so PayPal stays closed. FitPass is the checked record, not a promise that it will fit a real apartment. |
| 1:35–2:05 | Sandbox approval and capture receipt | I approve $129.00 in PayPal Sandbox. The server authorizes, checks the same room and price again, and captures only after that read-back. |
| 2:05–2:35 | Second product, change the room, void | This second authorization is not captured. I change the room so the item no longer fits, and SpaceProof voids it. No completed payment is recorded for this one. |
| 2:35–2:50 | FitPass and the voided status together | AI suggested the area. The buyer confirmed the size. The server decided the fit. PayPal held the money and then captured or voided it. |

## Recording checklist

- Use https://spaceproof.onrender.com/ after it has finished waking up.
- Hide passwords, the PayPal secret, and the Nebius key.
- Use a sandbox personal buyer. Do not use a live PayPal account.
- Show the catalog price before approval.
- Show the capture id only after the receipt appears.
- For the void, start from an authorized order that has no capture id. Do not reuse order `8NN90589CS658724M`; that authorization is already captured.
- If Nebius fails, draw the rectangle and say the rest of the purchase does not depend on the model.
- Export one take. Do not splice in an older payment.
