# Demo video script

Target length: under three minutes. Do not record or publish until a live void can be shown, or until the narration clearly says the void has not been completed on Sandbox.

## Sequence

1. State the problem in one sentence: a desk can be paid for before anyone checks whether it fits the corner.
2. Open SpaceProof. Upload a room photograph or use the sample diagram. Show the placement rectangle and say that the model proposes the area and does not measure it.
3. Confirm the sentence “This selected area has X cm usable width and Y cm usable depth.”
4. Run the catalog check. Show a dining table or desk that does not fit, and show that PayPal stays closed.
5. Select a product that fits. Show the FitPass: SKU, confirmed centimeters, clearance, budget, and the statement that this is not a physical certification.
6. Approve the catalog price and complete a PayPal Sandbox authorization with a personal buyer account.
7. If a second authorization is available, change the room so the item no longer fits, press capture, and show the provider void. If that void has not been done, do not invent it. Say that capture was verified for the Nook Desk and that the void path is still open.
8. End on the verified capture receipt or the void result, with the order amount in dollars.

## Do not show

- A fabricated payment status
- A claimed measurement taken from pixels
- Live PayPal credentials
- Benchmark numbers that were not produced by the evaluation scripts
